Database : Database is a collection of records in tabular format. 

    there are mainly 2 types of records 

    1) DBMS : database management system 

    2) RDBMS : Relational database management system

--------------------------------------------------------
what is table ?

    Table is a one kind place in database which is contain records 
    
    in simple language we can say that table is a combination 
    of row and column. 

    row : row which is represent specific single record 

    column : which is represent field of table 

    |     |
    V     V 
    -------------------------------
    id  |   Name |  Email      
    -------------------------------
    1   |   AAA  |  a@gmail.com    (r1)
    2   |   BBB  |  b@gmail.com    (r2)
    
    column :  id , name , email

DDL : commands : 

    1) CREATE

---------------------------------
4) DROP : to remove table from the database 

        and to remove database 

        syntax : 
        #drop table <tablename>;
        #drop database <databasename>;
--------------------------------------------
mysql> drop table student;
Query OK, 0 rows affected (0.03 sec)

mysql> desc student;
ERROR 1146 (42S02): Table '18junedb.student' doesn't exist
